Nota: no se indican horas de apertura; el contenido complementario no las inventa.

Justificación de contenedores sin equivalente semántico:
- En tarifas, los dos div.tabla-contenedor se mantienen porque envuelven cada
  tabla para habilitar desplazamiento horizontal en pantallas estrechas
  (overflow-x: auto); no representan una región temática del documento.
- No quedan elementos span ni otros div en las tres páginas.

Verificación:
- Cada página contiene un único main, además de header, nav principal y footer.
- Se conserva la secuencia y el nivel de los encabezados de cada página.
- Los enlaces internos, fragmentos y recursos locales apuntan a destinos existentes.

Formulario de reservas (paginas/reservas.html)
- El formulario usa POST y agrupa los controles en los fieldset Tus datos,
  Tu alquiler y Confirmación. Cada control tiene una etiqueta visible asociada
  y un atributo name para incluir su valor en el envío.
- El correo usa input type="email" para validar el formato propio de una dirección.
- El tipo de bicicleta usa un select porque la persona debe escoger una opción
  de un conjunto fijo de bicicletas disponibles.
- El horario usa botones de opción con el mismo name porque mañana y tarde son
  alternativas mutuamente excluyentes; el cliente selecciona una sola.

Comparación del trabajo de CSS propio con Bootstrap

| Área | Bootstrap | CSS propio (paginas/styless.css) |
|---|---|---|
| Estructura adaptable | Grilla responsive (`container`, `row`, `col-*`) y utilidades flex para distribuir contenido. | Ajustes específicos para la portada, pie de página y pantallas pequeñas; complementa la grilla, no la reemplaza. |
| Navegación y componentes | Navbar colapsable, botones, tarjetas, carrusel, tablas, formulario y modal; sus interacciones usan Bootstrap Bundle. | Ajusta colores, tipografía, radios, sombras y estados para que los componentes mantengan la identidad de Rueda Libre. |
| Formulario y tablas | Clases de formularios, validación visual, tablas y envoltura adaptable. | Personaliza el contraste, el foco, los mensajes de error, los bordes, fondos y espaciado de campos y tablas. |
| Identidad y presentación | Proporciona componentes y estilos base reutilizables, no la apariencia particular de la marca. | Define variables de color, estilos de encabezados, portada, paneles, imágenes del carrusel, tarjetas y pie de página. |
| Accesibilidad y movimiento | Ofrece componentes y utilidades que sirven de base; requiere marcado y atributos adecuados. | Añade enlace para saltar al contenido, foco visible, preferencias de movimiento reducido y ajustes visuales de estados interactivos. |

Conclusión: la página no está hecha únicamente con Bootstrap ni únicamente
con CSS propio. Bootstrap resuelve buena parte de la estructura responsive y
los componentes funcionales; la hoja propia adapta esos componentes y define
la apariencia de marca y los detalles específicos de la página. Ambos estilos
se cargan en conjunto y algunas variables de Bootstrap se personalizan desde
la hoja propia. Las pruebas de validación y teclado descritas arriba
corresponden a las comprobaciones previamente registradas; esta actualización
documenta el código revisado y no afirma nuevas pruebas en navegador.
